# 验证清单

## 硬件连接
- [ ] ST7789 屏幕通过 VSPI 正确连接 (CS=GPIO5, DC=GPIO16, RST=GPIO17, MOSI=GPIO23, SCK=GPIO18)
- [ ] 屏幕供电正常 (3.3V)

## 项目配置
- [ ] platformio.ini 包含所有必要依赖库
- [ ] WiFi SSID/密码已正确定义
- [ ] 和风天气 API Key 和 Host 已正确定义
- [ ] VSPI 引脚宏定义正确

## 屏幕驱动
- [ ] ST7789 初始化成功，240×240 模式
- [ ] 屏幕能正常清屏、填充颜色
- [ ] Adafruit GFX 绘图函数正常工作（画线、画圆、文字显示）

## 网络功能
- [ ] ESP32 能成功连接 WiFi
- [ ] WiFi 断开后自动重连
- [ ] NTP 时间同步成功，时区为 UTC+8
- [ ] 时间显示正确（时:分:秒）

## 天气数据
- [ ] 能成功请求和风天气 API
- [ ] JSON 解析正确（温度、湿度、天气代码、风速、体感温度）
- [ ] 30 分钟自动刷新正常
- [ ] API 请求失败时保留旧数据并提示

## UI 显示
- [ ] 大号数字时钟居中显示，每秒钟刷新
- [ ] 日期显示正确（年月日+星期），每分钟刷新
- [ ] 天气图标根据天气代码正确显示
- [ ] 温度、湿度、风速、体感温度正确显示
- [ ] 数据更新时间显示
- [ ] CRT 电视边框装饰效果正常
- [ ] 整体布局在 240×240 范围内完整、不溢出

## 容错处理
- [ ] WiFi 连接失败时屏幕有明确提示
- [ ] 天气数据加载中显示等待提示
- [ ] 天气 API 失败时显示错误提示且不覆盖正常 UI
- [ ] NTP 同步失败时显示"时间未同步"提示

## 综合测试
- [ ] 上电后全流程自动运行（WiFi→NTP→天气→显示）
- [ ] 长时间运行（≥4小时）无死机、无显示异常
- [ ] 网络断开后重新连上时自动恢复数据更新
