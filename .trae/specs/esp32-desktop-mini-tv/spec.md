# ESP32 桌面小电视 - 规格文档

## 概述

基于 ESP32 + ST7789 240×240 彩色屏幕的桌面小电视（WiFi 天气时钟），通过 WiFi 联网获取和风天气数据与 NTP 时间，以复古小电视 UI 风格展示时间、日期、天气信息。

## 硬件配置

| 项目 | 规格 |
|------|------|
| 主控 | Adafruit Feather ESP32 |
| 屏幕 | ST7789 240×240 RGB 彩色 TFT |
| 通信 | 硬件 SPI (VSPI) |
| CS | GPIO 5 |
| DC | GPIO 16 |
| RST | GPIO 17 |
| 背光 | 3.3V 常亮 |

## 软件依赖

| 库名称 | 用途 |
|--------|------|
| adafruit/Adafruit ST7735 and ST7789 Library | ST7789 屏幕驱动 |
| adafruit/Adafruit GFX Library | 图形绘制基础库 |
| arduino-esp32 WiFi | WiFi 联网 |
| Arduino HTTPClient | HTTP 请求天气 API |
| ArduinoJson | JSON 解析 |
| NTPClient | NTP 网络时间同步 |

### 颜色方案

- 背景色: 黑色 (0x0000) 或深色，模拟 CRT 电视
- 时钟数字: 亮青色/白色，大号字体
- 天气图标: 彩色（根据天气状态）
- 状态文字: 白色/浅灰色
- 装饰元素: CRT 模拟边框效果

### 字体层级

| 元素 | 近似字号 | 颜色 |
|------|---------|------|
| 时钟 (时:分) | 大 (≈7号字) | 青色/白色 |
| 日期 | 中 (≈4号字) | 灰色 |
| 温度 | 中 (≈4号字) | 白色 |
| 城市名 | 小 (≈2号字) | 浅灰色 |
| 底部信息 | 小 (≈2号字) | 浅灰色 |

## 功能要求

### 核心功能
1. 上电自动连接 WiFi（SSID/密码硬编码）
2. 通过 NTP 同步时间（使用 pool.ntp.org）
3. 每 30 分钟通过和风天气 API 获取实时天气
4. 显示天气信息（天气图标、温度、湿度、风向风速）
5. 显示当前时间（时:分，大号数字）和日期（年月日+星期）
6. 显示体感温度
7. 显示最后更新时间
8. 仿 CRT 小电视 UI 风格

### 容错处理
1. WiFi 连接失败 → 显示 "WiFi 连接失败" 提示，定期重试
2. 天气 API 请求失败 → 保留上次数据，显示 "数据更新失败"
3. NTP 获取失败 → 使用系统启动后的 millis() 计时，显示 "时间未同步"

## 性能与约束

- Flash 占用: 预计 < 1.5MB
- RAM 占用: 预计 < 80KB
- 天气 API 调用频率: ≤ 每 30 分钟一次
- NTP 同步: 启动时同步一次，之后每 1 小时校准
