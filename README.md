# ESP32 小电视天气时钟 

嗨！这是一个用 **ESP32** 做的迷你桌面天气站～

它有一个 **1.3 寸小屏幕**，能告诉你今天几度、要不要带伞、外面刮什么风，还会弹出气象预警提醒你注意安全！

##  它能干什么

- **☀️ 看天气** — 实时温度、体感温度、湿度、风向风力
- **🕐 看时间** — 大号数字时钟，还带秒数！时间自动从网络同步
- **📈 温度曲线** — 未来 7 个时间点的温度变化折线图
- **⚠️ 天气预警** — 台风、暴雨、暴雪... 有预警会自动通知你
- **🌧️ 分钟降水** — 未来 2 小时每 5 分钟降水强度，精确到毫米！
- **🔧 系统信息** — 芯片型号、内存、WiFi 信号、网络状态
- **🌐 Web 配置** — 手机浏览器就能改 API Key 和城市，超方便
- **🆕 首次配网** — 第一次使用手机连上设备 WiFi 热点就能配网
- **🇨🇳 中文显示** — 自带完整 GB2312-80 字库（7445 个字符，覆盖一二级汉字+符号），完美显示中文

##  接线方式

把屏幕的线接到 ESP32 的以下引脚：

| 屏幕引脚 | GPIO | 说明 |
|---------|------|------|
| TFT_CS | 5 | 片选（告诉屏幕"我要跟你说话啦"） |
| TFT_DC | 16 | 数据/命令切换 |
| TFT_RST | 17 | 复位 |
| TFT_MOSI | 23 | 数据发送 |
| TFT_SCK | 18 | 时钟信号 |
| BTN_PIN | 0 | BOOT 按键（不用额外接线） |

接好线之后的样子：

```cpp
// 屏幕初始化代码（已经写好了，你不需要改）
vspi = new SPIClass(VSPI);
vspi->begin(18, -1, 23, -1);  // SCK, MISO(不用), MOSI
tft = new Adafruit_ST7789(vspi, 5, 16, 17);  // CS, DC, RST
tft->init(240, 240);
tft->setRotation(1);  // 横屏模式
```

##  怎么让它跑起来

### 准备工作

1. 装好 [VS Code](https://code.visualstudio.com/) + [PlatformIO 扩展](https://platformio.org/)
2. 把 `src/config.h.template` **复制**一份，改名为 `src/config.h`
3. 打开 `src/config.h`，填上你的和风天气 API Key

### 需要填什么

```cpp
// ✏️ 这里要填你自己的 API Key！
#define WEATHER_API_KEY "你的和风天气API Key"  // ← 去 dev.qweather.com 免费申请

// 其他不用改，除非你想：
// #define WEATHER_HOST "devapi.qweather.com"   // API 地址
// #define WEATHER_NAME "Fuzhou"               // 默认城市
```

### 编译 & 上传

```bash
pio run              # 编译
pio run -t upload    # 上传到 ESP32
pio device monitor -b 115200  # 打开串口看日志
```

### 首次使用 5 步走

1. **烧录** → 把代码烧进 ESP32
2. **开机** → 屏幕上会出现 WiFi 热点名和 IP 地址
3. **连它** → 手机打开 WiFi，连上 `ESP32-Weather-XXXX`
4. **配置** → 手机浏览器打开，填写 API Key
5. **完成** → 设备自动联网，显示天气和时间～

>   `config.h` 里面有你自己的 API Key，千万不要提交到 GitHub！它已经被 `.gitignore` 保护了。

##  怎么玩（页面切换）

设备上只有一个 **BOOT 按钮**，玩法很简单：

| 操作 | 效果 |
|------|------|
| **短按一下**（<3 秒） | 切换页面：主页 → 预警 → 降水 → 系统 → 主页 |
| **长按 3 秒** | 重置 WiFi 设置，重启设备 |

### 页面一览

| 页面 | 里面有什么 |
|------|-----------|
| **主页面** | 天气 + 大时钟 + 体感详情 + 温度折线图 |
| **预警页面** | 气象预警信息（多条可切换，长文本自动滚动） |
| **降水页面** | 未来 2 小时降水强度图表 |
| **系统页面** | 芯片型号、内存、WiFi 信号、NTP 状态等诊断信息 |

##  Web 配置页面

设备连上 WiFi 后，在浏览器输入设备 IP 地址（比如 `192.168.1.100`），就能打开一个超好用的配置页面：

- 修改 API Key 和服务器地址
- 切换城市（输入城市名就行，自动定位）
- 实时保存，不用重启

##  技术彩蛋

这个小电视的身体里，有两个"小工人"在同时工作：

| 小工人 | 住在哪个核 | 负责什么 |
|--------|-----------|---------|
|   **网络小哥** | Core 0 | 连 WiFi、对时间、拉天气数据 |
|   **UI 小妹** | Core 1 | 画屏幕、检测按键、刷新时钟 |

他们通过 **互斥锁**（一个神奇的小本本）来交流，防止同时修改数据造成混乱。这样你的小电视就不会卡顿啦！

### 时间同步

设备会依次尝试 **15 台 NTP 时间服务器**（国家授时中心、阿里云×7、腾讯云×5、pool.ntp.org），总有一台能对上时间！

### 自动定位

开机后它会尝试用 3 个来源猜你在哪个城市：
1.   **ipip.net** 
2.   **B站**（对，就是那个小破站）
3.   **乐视**

如果都不行... 就用默认城市。

##  常见问题

### 为什么屏幕不亮？
检查接线对不对，特别是 CS、DC、RST 这三个引脚。

### 为什么连不上 WiFi？
长按 BOOT 3 秒重置 WiFi 设置，重新配网试试。

### 天气数据一直不更新？
去和风天气官网检查你的 API Key 有没有过期，免费版有调用次数限制哦。
